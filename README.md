# Queue Line Simulation

A C++ project that simulates a real-world **ticket queue and customer service system** using the **Queue data structure**.

The project demonstrates how a queue can be applied to a practical scenario where clients take tickets, wait for their turn, and are served according to the **First-In, First-Out (FIFO)** principle.

---

## 📌 Project Overview

This program simulates a ticket-based queue system similar to those used in banks, government offices, customer service centers, and other service environments.

The system allows you to:

* Create a queue with a specific prefix.
* Issue tickets to clients.
* Serve the next client in the queue.
* Track the number of waiting clients.
* Track the number of served clients.
* Determine which client is next.
* Display the current queue.
* Display detailed information about every waiting ticket.
* Calculate the expected service time for each ticket.

Each ticket contains information such as its number, creation time, number of waiting clients, and expected service time.

---

## 🧠 Data Structure

The main data structure used in this project is the **Queue**.

A queue follows the:

> **FIFO — First In, First Out**

principle.

This means that the first client who receives a ticket will be the first client to be served.

For example:

```text
Queue:

A1 → A2 → A3 → A4
↑
Next Client
```

If `A1` is served, it is removed from the front:

```text
A2 → A3 → A4
↑
Next Client
```

This behavior makes a queue an appropriate data structure for simulating real-world customer service systems.

## 🏗️ Design

The main class in the project is:

```cpp
clsQueueLine
```

This class represents a complete queue line.

### `clsQueueLine`

The class is responsible for managing the queue and providing operations such as issuing tickets, serving clients, and displaying queue information.

It contains:

* Queue prefix
* Total number of issued tickets
* Average service time
* A queue containing the waiting tickets

```cpp
queue<clsTicket> QueueLine;
```

### `clsTicket`

`clsTicket` is an inner class inside `clsQueueLine`.

It represents an individual ticket and stores:

* Ticket number
* Queue prefix
* Ticket creation time
* Number of waiting clients when the ticket was issued
* Average service time

The full ticket number is generated by combining the prefix and ticket number.

For example:

```text
A1
A2
A3
```

## ⚙️ Main Operations

### Issue a Ticket

The `IssueTicket()` function creates a new ticket and adds it to the back of the queue.

```cpp
QueueLine.push(Ticket);
```

This follows the standard queue **enqueue** operation.

---

### Serve the Next Client

The `ServeNextClient()` function removes the client at the front of the queue.

```cpp
QueueLine.pop();
```

This represents the **dequeue** operation.

The client who has been waiting the longest is served first.

---

### Check Waiting Clients

The `WaitingClients()` function returns the current number of clients waiting in the queue.

```cpp
QueueLine.size();
```

---

### Check Served Clients

The `ServedClients()` function calculates the number of clients that have already been served:

```text
Served Clients = Total Tickets - Waiting Clients
```

---

### Find Who Is Next

The `WhoIsNext()` function checks the front of the queue to determine which client will be served next.

```cpp
QueueLine.front();
```

## 🎫 Ticket Information

Each ticket stores information that can be used to estimate how long the client may need to wait.

The expected service time is calculated using:

```text
Expected Service Time =
Average Service Time × Waiting Clients
```

For example, if:

```text
Average Service Time = 5 minutes
Waiting Clients = 3
```

Then the estimated waiting time is:

```text
5 × 3 = 15 minutes
```

The ticket also records the system date and time when it was created.

## 🔄 Displaying the Queue

The project provides two different ways to display the ticket line.

### Right-to-Left

The queue can be displayed in the order in which clients will be served:

```text
A1 --> A2 --> A3 --> A4
```

### Left-to-Right

The queue can also be displayed in the reverse visual direction:

```text
A4 <-- A3 <-- A2 <-- A1
```

To demonstrate this, the project uses a temporary queue and a **Stack**.

The original queue is not modified while displaying the tickets.

---

## 🧩 Additional Data Structure: Stack

Although the main data structure of the project is the **Queue**, a `Stack` is also used in `PrintTicketsLineLTR()`.

The stack temporarily reverses the order of the tickets.

```text
Queue:
A1 → A2 → A3 → A4

After transferring to Stack:

A4
A3
A2
A1
```

Because a stack follows **LIFO (Last In, First Out)**, popping the stack produces the tickets in reverse order.

This demonstrates how different data structures can work together to achieve a specific operation.
